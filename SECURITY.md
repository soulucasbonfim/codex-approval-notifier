# Security Policy

## Supported Versions

Security fixes target the latest released version.

## Reporting a Vulnerability

Please do not open a public issue for sensitive security reports.

Report security concerns through GitHub private vulnerability reporting when available, or contact the maintainer directly through GitHub.

Include:

- Affected version or commit.
- Operating system.
- Steps to reproduce.
- Expected and actual behavior.
- Any relevant logs with secrets removed.

## Scope

This project does not approve or deny Codex actions. It only observes Codex approval requests and sends local desktop notifications.

Do not publish `codex-approval.events.log` or Codex logs without reviewing them first. They may contain command text or approval justifications from local sessions.
